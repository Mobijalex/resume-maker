# Markdown Reference for Resume Writing

## Quick Reference Guide

This guide provides a quick reference for writing your resume in Markdown format for the MD Resume Converter.

## Basic Syntax

### Headers

```markdown
# Your Full Name (H1 - Use only for your name)

## Section Header (H2 - Use for main sections)

### Subsection Header (H3 - Use for job titles, degrees)
```

### Text Formatting

```markdown
**Bold text** - Use for company names, institutions
_Italic text_ - Use for dates, durations

- Bullet point

* Alternative bullet point
```

### Links

```markdown
[Link text](https://example.com)
**LinkedIn:** linkedin.com/in/yourprofile
**Website:** yourwebsite.com
```

## Resume Structure Template

```markdown
# Your Full Name

**Email:** your.email@example.com
**Phone:** (555) 123-4567
**Location:** City, State
**LinkedIn:** linkedin.com/in/yourprofile
**Website:** yourwebsite.com

## Professional Summary

Brief 2-3 sentence summary highlighting your key qualifications and experience.

## Work Experience

### Job Title

**Company Name** | _Start Date - End Date_

- Accomplishment with quantifiable results (increased X by Y%)
- Responsibility that demonstrates key skills
- Achievement showing impact on business/team
- Technical implementation or leadership example

### Previous Job Title

**Previous Company** | _Start Date - End Date_

- Similar format for each position
- Focus on achievements over responsibilities
- Use action verbs (Led, Developed, Implemented)

## Education

### Degree Name

**Institution Name** | _Graduation Date_

**GPA:** 3.7/4.0 (optional, include if 3.5+)
**Relevant Coursework:** Course 1, Course 2, Course 3 (optional)

## Skills

### Technical Skills

- **Languages:** JavaScript, Python, Java, C++
- **Frontend:** React, Vue.js, HTML5, CSS3, TypeScript
- **Backend:** Node.js, Django, Express.js, REST APIs
- **Databases:** PostgreSQL, MongoDB, MySQL, Redis
- **Tools:** Git, Docker, AWS, Jenkins, Kubernetes

### Soft Skills

- Team Leadership
- Project Management
- Problem Solving
- Communication

## Certifications

### Certification Name

**Issuing Organization** | _Issue Date_

**Credential ID:** ABC123456 (optional)

## Projects

### Project Name

**Project Type** | _Date_

- Brief description of the project and your role
- Technologies used and challenges solved
- Results or impact achieved
- **Technologies:** React, Node.js, PostgreSQL, AWS
```

## Formatting Best Practices

### Contact Information

- Use bold labels: `**Email:**`, `**Phone:**`, etc.
- Keep format consistent
- Include LinkedIn and website if relevant

### Dates and Durations

- Use consistent format throughout
- Examples: `January 2022 - Present`, `2018 - 2022`, `Graduated May 2018`
- Use italics for dates: `_January 2022 - Present_`

### Bullet Points

- Start with action verbs
- Include quantifiable metrics when possible
- Keep each point to 1-2 lines
- Use parallel structure

### Section Organization

- List items in reverse chronological order
- Group related information together
- Use consistent formatting within sections

## Common Mistakes to Avoid

### ❌ Don't Do This

```markdown
# Resume (Don't use "Resume" as header)

**Job Title** (Don't bold job titles in headers)
Company Name | January 2022 - Present (Missing bold/italic formatting)
• Bullet point (Don't use special characters)
```

### ✅ Do This Instead

```markdown
# Your Full Name

### Job Title

**Company Name** | _January 2022 - Present_

- Bullet point with standard dash
```

## Special Sections

```markdown
- **Spanish:** Fluent
- **French:** Conversational
```

### Awards

```markdown
## Awards

### Award Name

**Organization** | _Date_

```

### Volunteer Experience

```markdown

### Role Title

**Organization Name** | _Duration_

- Description of volunteer work and impact
- Skills developed or demonstrated
```

## ATS-Friendly Tips

### Keywords

- Include relevant keywords from job descriptions
- Use industry-standard terminology
- List skills explicitly in Skills section
- Include both acronyms and full terms

### Structure

- Use clear, descriptive section headers
- Maintain consistent formatting
- Avoid complex formatting or special characters
- Keep structure logical and easy to scan

### Content

- Focus on achievements with quantifiable results
- Use action verbs to start bullet points
- Include relevant technical skills
- Tailor content to target positions

## Validation Checklist

Before submitting your resume, ensure:

- [ ] Name is in H1 header format
- [ ] Contact information includes email, phone, location
- [ ] Email is in valid format
- [ ] At least one work experience entry
- [ ] At least one education entry
- [ ] Consistent date formatting throughout
- [ ] Proper header hierarchy (H1 → H2 → H3)
- [ ] No special characters or symbols
- [ ] All sections use proper Markdown syntax

## Example Sections

### Professional Summary Examples

**For Experienced Professional:**

```markdown
## Professional Summary

Senior software engineer with 8+ years of experience in full-stack development,
specializing in React, Node.js, and cloud technologies. Proven track record of
leading cross-functional teams and delivering scalable applications serving
100K+ users.
```

**For Recent Graduate:**

```markdown
## Professional Summary

Recent Computer Science graduate with strong foundation in software development
and hands-on experience through internships and personal projects. Passionate
about web development and eager to contribute to innovative technology solutions.
```

### Work Experience Examples

**With Metrics:**

```markdown
### Senior Software Engineer

**Tech Solutions Inc.** | _January 2022 - Present_

- Led development of customer-facing web application serving 100K+ users, resulting in 25% increase in user engagement
- Architected microservices infrastructure using Node.js and AWS, reducing system downtime by 40%
- Mentored 3 junior developers and established code review processes that improved code quality metrics by 30%
```

**For Entry-Level:**

```markdown
### Software Development Intern

**StartupXYZ** | _June 2023 - August 2023_

- Developed responsive web components using React and TypeScript for customer portal
- Collaborated with senior developers on API integration and database optimization
- Participated in agile development processes and daily standups
```

### Skills Section Examples

**Technical Focus:**

```markdown
## Skills

### Programming Languages

- **Proficient:** JavaScript, TypeScript, Python, Java
- **Familiar:** C++, Go, Rust

### Web Technologies

- **Frontend:** React, Vue.js, Angular, HTML5, CSS3, Sass
- **Backend:** Node.js, Express.js, Django, Flask, REST APIs
- **Databases:** PostgreSQL, MongoDB, MySQL, Redis
```

**Balanced Approach:**

```markdown
## Skills

### Technical Skills

- **Languages:** JavaScript, Python, Java, SQL
- **Frameworks:** React, Node.js, Django, Express.js
- **Tools:** Git, Docker, AWS, Jenkins, Jira

### Core Competencies

- Full-Stack Development
- Database Design
- API Development
- Agile Methodologies
- Team Leadership
```
